🔬 NLA agent

Give an LLM agent a text and one tool: get_nla_explanation(position) — a natural-language autoencoder that verbalizes Qwen3.6-27B's layer-42 activation at any token of the text, scored by round-trip reconstruction (FVE). The agent probes positions and reports what the model was representing. Everything — system prompt, context block, tool calls, raw results — is shown below. The example texts are fully precached and served from this site, so probing them never touches Hugging Face; custom texts and uncached positions call the two Spaces (matryoshka, standard). Your API keys stay in this browser; nothing is sent anywhere except OpenRouter and, when needed, the Spaces.

  served from this site — probing them makes no Hugging Face request at all. Explanations are sampled
  at temperature 1; each position is cached after its first sample, so repeat probes return the

  can take 15–25 minutes — the page waits and shows progress.
